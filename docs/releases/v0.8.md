# PiHoleControls v0.8

## macOS Reliability Update

- Timed pauses use Pi-hole's server timer, so they still expire when the app closes.
- Changing server settings clears the old countdown and ignores stale responses.
- Connection testing supports both Pi-hole v5 and v6.
- Authentication, server, and connection failures are reported without misleading fallback errors.
- Blocking changes require a confirmed API response instead of accepting an HTTP success code alone.
- Missing statistics are reported as unavailable rather than shown as zero.
- Automated tests use isolated preferences and credentials.
- Release packaging validates the archive, executable, and signature before publishing.

Requires macOS 26.1 or later. Includes Apple Silicon and Intel builds in one app.
The app is signed but not notarized; macOS may require explicit approval on first launch.
This release uses an Apple Development identity because no Developer ID Application
identity is configured on the release machine. Older ad-hoc-signed installations
may require Keychain access approval or a one-time credential entry.

This is a macOS release only. The iOS companion remains an unfinished scaffold in
the source tree. Temporary domain exceptions remain on their separate, unmerged
branch and are not included in this release.
